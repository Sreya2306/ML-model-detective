# ML Model Detective

A beginner machine-learning project that audits tabular datasets and baseline classification models for data-quality and evaluation risks.

## Current stage

Stage 0 — Project setup  
Stage 1 — Learning Python fundamentals

## Planned features

- Dataset profiling
- Missing-value and duplicate detection
- Class-imbalance analysis
- Baseline model training
- Classification-metric audit
- Possible leakage and validation warnings

## Tech stack

Python, pandas, NumPy, scikit-learn, matplotlib, Streamlit
